## 职责、范围与权限

- 本插件负责人格、公共/管理员/其他私聊/群聊核心稿、长期记忆与关系图、日记、记忆整理和上下文压缩、自身备份恢复。QQ连接、原始消息存档、工作区、白名单、回复节奏、媒体/语音/生图、主动聊天和掉线提醒在QQ插件。
- 默认只作用于QQ会话，不修改普通网页会话的全局默认预设；用户可显式改生效范围。只装QQ插件可使用dsh默认人格，只装本插件可按需启用网页会话。
- 长期记忆按`master`、`public`、`group:<群号>`、`user:<QQ号>`分域：管理员记忆接口可读取全部域；群和其他私聊仅公共域与自身域。管理员私密资料不能通过普通群/私聊记忆接口返回。
- 保留用户原终端、文件读写等工具权限；分域只约束记忆接口，不构成操作系统文件沙箱。不能擅自关工具，也不能宣称文件绝对隔离。
- 人格自改工具的管理员权限、硬规则与可选审核保留；外部插件调用也须检查目标会话、生效范围和访问权限，不因接入服务绕过隔离。

## 人格与上下文

- 人格/核心记忆现稿在受管会话下一次模型请求动态读取，旧会话无需/reset。不得用重建会话、删历史或强制/reset代替动态生效机制。
- 保留`system-prompt/assemble`组装机制、预设范围及排除规则；人格按字面量处理，不展开`{{...}}`模板。空稿保留预设人格，不清空其他系统说明。
- 不自动引入工作目录AGENT.md覆盖，也不擅自启用第二个人格来源。其他插件若complete替换提示可能覆盖本插件，需核查真实组装及最终请求，不能凭设置预览判定最终生效。
- 编辑器区分正文保存与设置保存、已保存正文与未保存草稿；导入仅改草稿。修订摘要冲突返回409并保护新稿，外部原子替换须可重新读取，不自动猜测合并。
- 人格HTML注释过滤默认关闭；开启只影响注入正文，原稿、历史及备份保留；核心稿不套用此过滤。组装记录仅反映真实钩子阶段，不额外调用模型验证，不保存敏感正文。
- 缓存优化先核对稳定提示前缀、动态记忆/时间信息和历史请求，不能牺牲有效记忆与历史或承诺固定命中率。
- 设置保留“更多→设置”和插件管理入口；同级分类互斥展开，收起不丢草稿；支持深浅主题与窄屏，帮助文字正式说明用途、单位、默认值、范围和例外。

## 与QQ插件协作

- 保留`companion-core`配置、`companion`服务及既有事件契约；展示名和包名变化不能直接重命名持久化命名空间。
- 使用QQ服务的会话身份/管理员分类与映射，向QQ方提供默认陪伴预设、受管会话判断、上下文策略与整理等可选接口。相关代码入口为`src/companion/index.ts`和`service.ts`，QQ方见`src/qq/features.ts`。
- 修改域分类、会话ID/工作区迁移、提示组装、整理或压缩接口时核对两边，分别运行测试及联调；缺少另一插件时可独立加载。
- 上下文压缩、记忆整理、日记、嵌入和聊天模型是不同用途；变更回退/选择规则时核对实际调用与配置，不能把所有后台任务强绑会话当前聊天模型。

## 数据、备份与迁移

- 默认数据根`DSH_HOME/persona-memory`；人格/核心稿只备份现稿。可选备份为人格、核心记忆、日记、长期记忆与关系图、本插件设置，不备份QQ原始消息或运行环境。
- 独立目录、计划与保留计数，默认最多5份；手动/定时/恢复前备份统一计数，新包成功后清理最旧包。没有电脑自动同步或完整环境打包。
- 上传tar.gz先识别内容再由用户多选恢复，未选类别保留；校验owner、路径、大小、SHA256及格式，旧包兼容和跨插件归属保护保留。设置不导出密钥。
- 新包自带逐文件说明、实际SQLite表列/引用与迁移指南，见[备份格式](BACKUP-FORMAT.md)。任何数据结构/备份选择变化同步修改生成说明、版本兼容和恢复测试。
- 迁往不同插件须保留分域、有效/已遗忘/被替代状态、关系与整合引用；目标不支持的内容单独报告，不能公开合并管理员记忆或重新激活已遗忘项。向量模型/维度不兼容时从正文重建。
- 私人数据、密钥、真实会话不放进公开测试、截图、报告或交接。迁移前保护原件，不用已删除旧备份作假定恢复来源，不对已拆分环境重复运行旧迁移。

## 构建、验证与发行

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm test
node scripts/check-client.mjs
node --check lib/client.js
```

- TypeScript主体在`src/companion`，UI在`src/client`；编辑源码，不直接修改lib代替修复。UI变更在真实宿主核对深浅主题、窄屏、保存/冲突和折叠草稿。
- 涉及权限、域、记忆/关系、遗忘、提示装配、压缩、恢复/迁移时验证对应行为；联调在QQ仓库运行，两个包都构建并做真实dsh安装验证。使用假模型/假OneBot，不消耗真实额度或发送真实消息。
- 按改动选择验证，纯文档修改查链接、事实、隐私；记录实际执行和跳过项，不用旧测试数冒充本轮结果。
- 同步package版本、CHANGELOG、README安装命令/链接、tgz和SHA256SUMS。若QQ安装器引用本包版本，更新其引用和校验值；不要求无关运行代码跟着改版。同步本交接及受影响的用户说明。
- 独立安装仍用dsh运行账号和同一DSH_HOME。升级前等回复、生图、待发及更新器busy/analyzing/notifying/testingModel全部结束，再复核持久turn/空闲状态，准备profile/存储/包与数据结构兼容回退后才停dsh；HTTP健康不等于业务空闲。
- 不顺手改SnowLuma登录、密码、端口、资源或启动方式，不覆盖用户人格/记忆与模型选择，不因恢复或测试引入额外业务备份计划。
- 公开提交前扫描隐私和密钥、保留许可和来源；提交/发行/部署/真实验证状态分开记录。服务器凭证和现场状态由部署方私有交接，不放本仓库。
