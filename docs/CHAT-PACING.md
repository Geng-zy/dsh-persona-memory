# 按聊天类型设置模拟打字

位置：**更多 → 设置 → SnowLuma陪伴助手 → 聊天与回复 → 回复节奏**。

管理员私聊、其他人私聊、群聊各有一张设置卡片，分别配置：

- 模拟打字开关。
- 打字速度：每分钟非空白字符数，0表示不等待。
- 最短等待与最长等待，单位秒。

例如：管理员私聊60字/分钟、其他私聊120字/分钟、群聊240字/分钟，同一句5字回复分别计算为5秒、2.5秒、1.25秒，再应用各自的最短/最长范围。

**管理员在群里发言仍使用群聊的打字设置**；管理员原有群发言限频豁免保留，这两项用途不同。分段回复按该类打字速度逐段计算，仍受现有分段等待上限约束。模拟打字不包含模型生成、图片生成、语音合成和群发送频率等待。生图图片直接发送，不因文字打字速度增加等待。

## 旧设置兼容

此前`typingPrivate`同时控制两类私聊，`typingGroup`控制群聊，`typingCharsPerMinute/typingMinSeconds/typingMaxSeconds`为共享参数。新版保留这些旧值作为未单独设置时的兼容来源，避免升级改变已配置的回复节奏。

新增`typingAdminPrivate`及三类`typing{AdminPrivate|Private|Group}{CharsPerMinute|MinSeconds|MaxSeconds}`参数。其他私聊/群聊的开关继续使用`typingPrivate/typingGroup`，不重复创建同义配置。

设置页首次编辑任一打字参数时，会先将各类当前继承值写入草稿，统一保存后各自独立；之后关闭普通私聊打字不会连带关闭管理员私聊。直接手工配置旧字段的环境，建议显式设置三类新字段；删除新字段或恢复默认将回到旧兼容值。

## 设置卡片展开行为

统一设置页同一时间仅展开一个顶层设置卡片。打开另一张时自动收起上一张，搜索结果和不同用途分组遵循同一规则；已打开过的编辑器保留挂载，收起不丢失未保存草稿。保留“全部收起”，不再提供与互斥展开冲突的“全部展开”。生图内部的同级高级分组也采用互斥展开。
